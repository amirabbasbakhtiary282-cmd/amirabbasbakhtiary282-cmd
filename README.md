## 🚀 پروژه ویژه - ارزان‌کالا

### 🛒 سامانه فروشگاهی ارزان‌کالا (ArzanKala)

> یک پلتفرم تجارت الکترونیک کاملاً ریسپانسیو، مدرن و بهینه که برای ارائه تجربه خرید سریع و مدیریت یکپارچه محصولات طراحی و پیاده‌سازی شده است.

<table align="center" width="100%">
<tr>
<td width="50%" align="right">

**ویژگی‌های کلیدی پروژه:**
- 🖥️ **رابط کاربری مدرن:** طراحی واکنش‌گرا متناسب با انواع نمایشگرها.
- 📦 **دسته‌بندی و جستجو:** سیستم ساختاریافته برای مرور آسان محصولات الکترونیکی.
- 🛒 **سبد خرید پویا:** مدیریت اقلام انتخابی کاربر به صورت لحظه‌ای.

</td>
<td width="50%" align="right">

**فناوری‌های به‌کاررفته:**
- ⚙️ **سمت سرور:** Node.js و Express.js برای مدیریت مسیرها و توابع API.
- 🗄️ **پایگاه داده:** پایگاه داده رابطه‌ای امن MySQL.
- 🌐 **استقرار ابری:** پیاده‌سازی و راه‌اندازی زنده روی بستر ابری (Render).

</td>
</tr>
</table>
