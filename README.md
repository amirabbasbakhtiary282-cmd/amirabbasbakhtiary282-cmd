## 🧑‍💻 درباره من

<div dir="rtl" align="right">

سلام! من **امیرعباس بختیاری** هستم؛ یک توسعه‌دهنده دانش‌آموز که عاشق ساختن چیزهای مفید با کد هستم. 🌱

مسیر من توی برنامه‌نویسی با کنجکاوی شروع شد و حالا به جایی رسیده که پروژه‌های واقعی می‌سازم، دیپلوی می‌کنم و یاد می‌گیرم چطور تکنولوژی می‌تونه مشکلات واقعی رو حل کنه.

- 💻 **تمرکز اصلی:** توسعه وب و مبانی فول‌استک
- 🌐 **پروژه شاخص:** ساخت و دیپلوی **ارزان‌کالا** — یک اپلیکیشن فروشگاهی کامل
- 🏆 **افتخار:** راه‌یابی به مرحله کشوری **جشنواره نوجوان خوارزمی** پس از کسب رتبه استانی
- 🤖 **علاقه‌مندی:** هوش مصنوعی و راهکارهای داده‌محور
- 📚 **همیشه در حال:** یادگیری، آزمایش کردن و بهتر شدن

<div dir="rtl" align="right">

یک پروژه فروشگاهی واقعی که برای تمرین توسعه وب در دنیای واقعی، اتصال بک‌اند و مدیریت دیتابیس ساخته شده. این پروژه نشون می‌ده که می‌تونم یک ایده رو از صفر به یک محصول قابل استفاده تبدیل کنم.

**✨ ویژگی‌های کلیدی:**

- 🎨 رابط کاربری واکنش‌گرا و سازگار با موبایل
- 📦 دسته‌بندی محصولات و جستجو
- 🛒 عملکرد کامل سبد خرید
- ⚙️ سرویس‌های بک‌اند با Node.js و Express.js
- 🗄️ یکپارچه‌سازی با دیتابیس MySQL
- 🔌 مفاهیم REST API و دیپلوی زنده
